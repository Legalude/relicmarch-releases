# Relicmarch — test builds

Desktop builds of **Relicmarch**, a 2D pixel-art roguelite / idle RPG, for friends testing the game. (Source code is
not in this repository.)

## Install (Windows 10/11, 64-bit)
1. Open the [latest release](https://github.com/Legalude/relicmarch-releases/releases/latest) and download
   `Relicmarch_<version>_x64-setup.exe`.
2. Run it. Windows may say **"Windows protected your PC"** because the installer isn't commercially code-signed —
   click **More info → Run anyway**.
3. The game installs for your user account only and starts.

## Updates
The game checks for new versions when it starts (and from **Settings → About → Check for updates**). When one is
available, click **Install & restart** — your progress is saved first and kept.

## Saves
Saves live in `%APPDATA%\com.relicmarch.game\` (with automatic backups), not in the install folder.
**Settings → Save Slots → Export** makes a copy you can keep or send along with a bug report.
